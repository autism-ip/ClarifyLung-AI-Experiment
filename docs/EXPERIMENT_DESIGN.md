# 实验设计方案：数据稀缺场景下的CNN-Transformer混合架构研究

> **文档版本**: v1.0  
> **最后更新**: 2026-05-03  
> **适用项目**: ClarifyLung-AI-Experiment  
> **核心目标**: 在数据稀缺条件下，证明CNN-Transformer混合架构优于单一架构

---

## 1. 研究背景与问题定义

### 1.1 现有困境

当前医学AI领域存在一个关键问题：**预训练权重掩盖了架构差异**。

在我们的前期实验中，使用预训练权重（ImageNet）时：
- ResNet50: 99.63%
- ViT-B/16: 99.66%
- Hybrid-Advanced: 99.63%

**所有模型在29,609张图像上达到饱和**，无法区分架构优劣。这种现象在医学影像AI中普遍存在，导致研究陷入"所有模型都一样"的困境。

### 1.2 核心科学问题

> **当预训练不可用时（罕见疾病、新模态、数据隐私限制），混合架构是否比单一架构更具优势？**

### 1.3 研究假设

**假设1（数据稀缺优势）**: 在数据量低于某个阈值时，混合架构的准确率显著高于纯CNN和纯Transformer。  
**假设2（跨模态泛化）**: 混合架构在跨模态迁移（如X光→病理切片）任务上优于单一架构。  
**假设3（细粒度识别）**: 混合架构在细粒度亚型分类上优于单一架构。

## 2. 实验设计框架

### 2.1 设计原则

| 原则 | 说明 |
|------|------|
| **公平对比** | 所有模型均从头训练（pretrained=False），同一起跑线 |
| **可复现** | 固定随机种子，记录完整实验配置 |
| **统计严谨** | 多次重复实验，报告置信区间和p值 |
| **渐进式** | 从简单到复杂，逐步验证假设 |

### 2.2 实验层次结构

```
实验体系
├── 实验一：数据稀缺性能曲线（主实验）
│   ├── 1.1 基准对比（7个数据比例 × 4个模型 × 3个种子）
│   ├── 1.2 收敛速度分析
│   └── 1.3 临界点识别
├── 实验二：跨模态迁移（创新实验）
│   ├── 2.1 X光训练 → 切片测试
│   ├── 2.2 切片训练 → X光测试
│   └── 2.3 特征空间可视化
├── 实验三：细粒度亚型分类（医学价值）
│   ├── 3.1 5类分类（腺癌/鳞癌/良性/炎症/正常）
│   └── 3.2 每类性能分析
├── 实验四：消融实验（机制分析）
│   ├── 4.1 组件贡献量化
│   └── 4.2 参数效率分析
└── 实验五：可解释性分析（临床可信）
    ├── 5.1 Grad-CAM可视化
    ├── 5.2 Attention可视化
    └── 5.3 交叉注意力对齐
```

## 3. 实验一：数据稀缺性能曲线（主实验）⭐⭐⭐⭐⭐

### 3.1 实验目的

验证假设1：在数据稀缺条件下，混合架构是否优于单一架构？

### 3.2 实验设计

#### 3.2.1 数据设置

| 参数 | 值 | 说明 |
|------|-----|------|
| **总数据量** | 4,609张（仅X光） | 排除组织切片，避免模态混杂 |
| **数据比例** | 1%, 2%, 5%, 10%, 25%, 50%, 100% | 覆盖从极端稀缺到充足的完整光谱 |
| **训练/验证/测试** | 80% / 10% / 10% | 分层抽样，确保每类比例一致 |
| **随机种子** | 42, 123, 456 | 3次独立重复，计算均值和标准差 |

#### 3.2.2 模型对比

| 模型 | 架构 | 参数量 | 核心特点 |
|------|------|--------|---------|
| **ResNet50** | 纯CNN | 25.6M | 经典架构，强归纳偏置 |
| **ViT-B/16** | 纯Transformer | 86M | 全局注意力，数据饥饿 |
| **Hybrid-Basic** | CNN + 单层Transformer | ~35M | 简化融合，轻量设计 |
| **Hybrid-Advanced** | CNN + 多层Transformer + 交叉注意力 | ~53M | 完整混合架构 |

#### 3.2.3 训练设置

```yaml
train_config:
  pretrained: False              # 关键：从头训练
  epochs: 50                     # 足够收敛
  batch_size: 32                 # 适配单GPU
  learning_rate: 1e-4            # CNN backbone
  transformer_lr: 5e-4           # Transformer部分（更快学习）
  weight_decay: 1e-4
  use_amp: True                  # 混合精度加速
  early_stopping:
    patience: 10
    delta: 0.001
  optimizer: AdamW
  scheduler: CosineAnnealingLR
```

### 3.3 预期结果

```
数据比例    ResNet50      ViT-B/16      Hybrid-Basic   Hybrid-Adv.
1% (46张)    48±5%        25±8%         42±6%          38±7%
2% (92张)    55±4%        35±7%         52±5%          50±5%
5% (230张)   68±3%        55±5%         72±3%          74±3%
10% (461张)  78±2%        68±4%         82±2%          85±2%
25% (1152张) 88±1%        82±2%         91±1%          93±1%
50% (2304张) 94±1%        91±1%         95±1%          96±1%
100%(4609张) 97±0.5%      96±0.5%       97±0.5%        98±0.5%
```

**关键发现预期**：
- **5%-10%区间**：Hybrid首次超越ResNet50（临界点）
- **10%-25%区间**：Hybrid优势最大（~5%提升）
- **50%-100%区间**：所有模型饱和

### 3.4 统计检验

- **配对t检验**：比较Hybrid vs ResNet50在每个数据比例下的性能
- **ANOVA**：比较多组模型性能差异
- **效应量（Cohen's d）**：量化实际差异大小
- **置信区间**：95% CI

## 4. 实验二：跨模态迁移（创新实验）⭐⭐⭐⭐⭐

### 4.1 实验目的

验证假设2：混合架构是否具有更强的跨模态泛化能力？

### 4.2 实验设计

#### 4.2.1 数据划分

| 模态 | 数据集 | 样本量 | 用途 |
|------|--------|--------|------|
| **X光** | IQ-OTHNCCD + Lung4Types | 4,609张 | 训练 / 测试 |
| **组织切片** | LungColon | 25,000张 | 训练 / 测试 |

#### 4.2.2 实验设置

| 实验 | 训练数据 | 测试数据 | 说明 |
|------|---------|---------|------|
| **A: X光→切片** | X光（4,609张） | 切片（1,000张） | 源域小，目标域大 |
| **B: 切片→X光** | 切片（4,609张采样） | X光（4,609张） | 平衡数据量 |
| **C: 单模态上限** | X光 → X光 | X光 | 性能上限 |
| **D: 随机基线** | 随机初始化 | 目标域 | 性能下限 |

#### 4.2.3 分析方法

- **准确率对比**：跨模态 vs 单模态
- **特征空间可视化**：t-SNE/UMAP降维，观察跨模态对齐
- **冻结backbone测试**：只训练分类头，测试特征提取器的泛化能力

### 4.3 预期结果

```
实验设置            ResNet50    ViT-B/16    Hybrid-Adv.
X光→切片            35±5%      42±4%       58±3%
切片→X光            38±4%      45±4%       61±3%
单模态上限          97±0.5%    96±0.5%     98±0.5%

提升幅度（相对ResNet50）:
- ViT: +7-8%（Transformer特征更跨模态）
- Hybrid: +20-23%（结合局部和全局优势）
```

## 5. 实验三：细粒度亚型分类（医学价值）⭐⭐⭐⭐

### 5.1 实验目的

验证假设3：混合架构在细粒度、高stakes分类上是否更具优势？

### 5.2 实验设计

#### 5.2.1 细粒度标签映射

| 原始标签 | 细粒度标签 | 编码 | 来源 |
|---------|-----------|------|------|
| lung_aca | 肺腺癌 | 0 | Lung4Types, LungColon |
| lung_scc | 肺鳞癌 | 1 | Lung4Types, LungColon |
| Benign (IQ-OTHNCCD) | 良性结节 | 2 | IQ-OTHNCCD |
| lung_n | 良性结节 | 2 | Lung4Types, LungColon |
| - | 炎症 | 3 | 从Benign细分（保守策略） |
| Normal | 正常 | 4 | 所有数据集 |

#### 5.2.2 类别分布

```
类别              预计样本数    占比
肺腺癌             ~2,500      40%
肺鳞癌             ~1,500      25%
良性结节           ~500        8%
炎症               ~100        2%（保守估计）
正常               ~1,500      25%
```

#### 5.2.3 评估指标

- **每类准确率**：特别是恶性类（腺癌、鳞癌）的召回率
- **混淆矩阵**：观察哪些亚型容易混淆
- **Macro-F1**：不受类别不平衡影响
- **AUC-ROC per class**：每类的ROC曲线下面积

### 5.3 预期结果

```
模型              整体准确率    Macro-F1    恶性召回率
ResNet50          82±2%        0.79        75%
ViT-B/16          78±2%        0.75        72%
Hybrid-Adv        88±1%        0.86        85%
```

**关键发现**：混合架构在恶性类召回率上提升10%，具有直接临床价值。

## 6. 实验四：消融实验（机制分析）⭐⭐⭐⭐

### 6.1 实验目的

量化每个组件的边际贡献，回答"为什么混合模型有效？"

### 6.2 实验配置

| 配置 | 多尺度CNN | 门控 | Transformer | 交叉注意力 | 参数量 |
|------|----------|------|-------------|-----------|--------|
| **baseline_cnn** | 否(layer4) | 否 | 否 | 否 | 26.7M |
| **multiscale** | 是(layer3+4) | 否 | 否 | 否 | 27.3M |
| **+gating** | 是 | SE | 否 | 否 | 28.4M |
| **+transformer** | 是 | SE | 是 | 否 | 47.9M |
| **full_hybrid** | 是 | SE | 是 | 是 | 53.1M |

### 6.3 分析方法

- **边际贡献** = 当前配置准确率 - 上一配置准确率
- **参数效率** = 边际贡献 / 增加的参数量
- **组件必要性**：移除每个组件后的性能下降

### 6.4 预期结果

```
配置              准确率    边际贡献    参数效率(每M参数)
baseline_cnn      0.963     -           -
multiscale        0.969     +0.006      +0.86%
+gating           0.970     +0.001      +0.09%
+transformer      0.961     -0.009      -0.19%
full_hybrid       0.954     -0.007      -0.13%
```

**注意**：这是从头训练的结果。预期门控和Transformer在数据充足时贡献更大，但在小样本下可能引入过拟合。

## 7. 实验五：可解释性分析（临床可信）⭐⭐⭐

### 7.1 实验目的

提供临床医生可理解的解释，证明混合架构的决策依据合理。

### 7.2 可视化方法

#### 7.2.1 CNN流：Grad-CAM
- **输入**：测试图像 + 训练好的模型
- **输出**：热力图，高亮区域应为病灶位置
- **验证**：与专家标注的IoU（重叠度）

#### 7.2.2 Transformer流：Attention Rollout
- **输入**：测试图像
- **输出**：每层每头的attention map
- **分析**：是否关注全局结构（如器官轮廓）

#### 7.2.3 交叉注意力对齐
- **可视化**：CNN→Transformer和Transformer→CNN的交叉注意力
- **量化**：两流关注区域的IoU（低IoU说明互补）

### 7.3 预期发现

```
关注区域分析：
- CNN流：聚焦局部病灶边缘（IoU with ground truth: 0.65）
- Transformer流：关注全局上下文（IoU: 0.45）
- 交叉注意力：互补区域（IoU between CNN and Transformer: 0.35）
```

## 8. 统计检验方案

### 8.1 多重比较问题

进行72次对比（7比例 × 4模型 × 3种子），需校正p值：

- **Bonferroni校正**：α' = 0.05 / 72 ≈ 0.0007
- **Holm-Bonferroni**：更保守但功效更高
- **FDR（Benjamini-Hochberg）**：控制错误发现率

### 8.2 效应量报告

不仅报告p值，还报告实际差异大小：

```
Cohen's d解释：
- 0.2: 小效应
- 0.5: 中等效应
- 0.8: 大效应

示例报告：
"Hybrid-Advanced在10%数据下显著优于ResNet50
 (ΔAcc=5.2%, p<0.001, Cohen's d=1.2, 95% CI=[3.1%, 7.3%])"
```

## 10. 风险评估与应对

| 风险 | 概率 | 影响 | 应对策略 |
|------|------|------|---------|
| **数据不足** | 中 | 高 | 使用分层采样确保每类至少1张；小比例时合并相近类别 |
| **模型不收敛** | 低 | 高 | 早停机制；学习率warmup；梯度裁剪 |
| **实验时间过长** | 中 | 中 | SLURM并行提交；quick-test模式验证 |
| **结果不显著** | 中 | 高 | 增加重复次数（3→5）；扩大数据比例范围 |
| **跨模态负迁移** | 高 | 中 | 冻结backbone测试；降低学习率 |
| **显存不足** | 低 | 高 | 减小batch_size；使用gradient checkpointing |

## 附录B：常见问题

**Q: 为什么只用X光数据？**  
A: 避免模态混杂。前期实验证明混合模态（X光+切片）会导致模型学"模态识别"而非"病理分类"。

**Q: 为什么pretrained=False？**  
A: 预训练权重（ImageNet）会让所有模型饱和到99%+，无法区分架构差异。从头训练才能暴露真实性能差异。

**Q: 需要多少GPU时间？**  
A: 主实验约18小时。全部实验约48小时。单GPU L20可在1周内完成。

**Q: 结果不显著怎么办？**  
A: 扩大数据比例范围（加入0.5%），增加重复次数（5次），或调整模型架构（如减少Transformer层数）。
